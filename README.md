# 公众号文章归档

一款用于整理微信公众号文章的 Windows 桌面工具，可将支持的内容保存到本地，方便查阅与整理。

## 功能简介

- **文章与合集**：通过链接整理公开的公众号文章或合集。
- **按日期归档**：提供公众号历史文章的日期范围下载功能，需要配合电脑版微信使用。
- **自选保存位置**：将文章保存到自己选择的电脑目录。
- **Codex / MCP**：支持通过 MCP 连接 Codex，使用对话发起下载并查看任务进度。

## 当前状态

项目处于测试阶段。本仓库目前用于产品介绍和未来官网内容的准备，暂不提供软件下载、软件源码或在线服务。

公众号历史文章的获取范围取决于微信的返回结果和授权状态，不保证覆盖全部历史文章；部分文章或图片可能因验证、删除或访问限制无法保存。使用时请尊重内容权利人的合法权益。
